# ryan-mendes.github.io

Personal site of Ryan Mendes, served by GitHub Pages.

Plain HTML, CSS and JavaScript with no build step and no framework:

- A cinematic intro with letterbox bars, film grain, a lit portrait and staggered type
- Technology icons orbiting the portrait on two tilted rings, passing in front of and behind it
- Scroll reveals, cursor-following card highlights and subtle pointer parallax
- Respects `prefers-reduced-motion`

**Live:** https://ryan-mendes.github.io
